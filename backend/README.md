# ProcureFlow Backend API & Engine

Modular Express backend for ProcureFlow MSME procurement platform.

## Scripts
- `npm run seed`: Seeds database with realistic MSME test accounts, RFQs, quotes, orders, and audit trail.
- `npm test`: Runs unit tests (`pricing-engine`, `state-machine`) and API integration tests with Vitest.
- `npm run dev`: Starts Express development server on port 5000 with nodemon.
- `npm start`: Starts production Node server.
